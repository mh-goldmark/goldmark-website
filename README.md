# Gold Mark Work Life

Premium business center landing page for **Gold Mark Work Life Business Center LLC** at Cityland Mall, Dubai.

## Stack

- [Next.js](https://nextjs.org/) (App Router) + React + TypeScript
- [Tailwind CSS](https://tailwindcss.com/) v4
- Google Fonts: **Playfair Display** (headings), **Montserrat** (body / nav)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Scope

Phase 1 landing page only (single route). Additional pages, bilingual content, CMS, and CRM wiring are planned for later phases per the IT proposal.
